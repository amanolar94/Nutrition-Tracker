# Ημερολόγιο, αγαπημένα και κινητά — MCP 3.2.0

Οι αλλαγές επεκτείνουν την υπάρχουσα εφαρμογή, το ίδιο Supabase project και το ίδιο
ιδιωτικό plugin. Δεν αλλάζουν λογαριασμούς ή ιστορικά δεδομένα.

## Ενεργοποίηση

1. Με τις προηγούμενες migrations ήδη εφαρμοσμένες, τρέξε στο Supabase SQL Editor
   το [20261020_diary_usability.sql](../supabase/migrations/20261020_diary_usability.sql).
   Είναι προσθετικό και μπορεί να εκτελεστεί ξανά. Διατηρεί τα παλιά mutation receipts,
   τα γεύματα, τους στόχους και την κατάργηση των προσωπικών κλειδιών. Μην τρέξεις
   ξανά παλιότερη migration που αντικαθιστά το `write_nutrition` μετά από αυτήν.
2. Ανέβασε τον κώδικα στο ίδιο Vercel project. Δεν χρειάζεται νέο env variable, OAuth
   app, hook ή άλλο Supabase project.
3. Το `/mcp/status` πρέπει να αναφέρει `server_version: 3.2.0`, `tool_count: 20`
   και `dashboard_approval_required: false` μετά το deployment. Το status ελέγχει
   το schema του server, όχι αν εφαρμόστηκε η migration.
4. Ανανέωσε τη λίστα εργαλείων στην υπάρχουσα σύνδεση ChatGPT και ενημέρωσε τις
   [οδηγίες του υπάρχοντος plugin](plugin-instructions.md). Αν χρειάζεται,
   επανασύνδεσε τον ίδιο server `/mcp` και άνοιξε νέα συνομιλία.

## Τι αλλάζει

- Συμπαγής ημερήσια πρόσληψη/macros, έπειτα εκτιμώμενο ισοζύγιο και γεύματα.
  Η συντήρηση χωρίς άσκηση παραμένει διαφορετική από τον στόχο πρόσληψης.
- Φίλτρα Όλα / Γεύματα / Workout fueling, επεξεργασία, προαιρετική ώρα Αθήνας,
  επανάληψη και αγαπημένα. Το fueling μετράει μία φορά στα σύνολα.
- Η επανάληψη ανοίγει μόνο πρόχειρη φόρμα. Κλείσιμο/ακύρωση δεν γράφει δεδομένα.
  Η αποθήκευση απαιτεί το κουμπί της φόρμας ή ρητή επιβεβαίωση στο ChatGPT πριν
  από το addMeal. Η αποθήκευση αγαπημένου δεν αποτελεί καταγραφή πρόσληψης.
- Ο τύπος ανάπαυσης/προπόνησης αποθηκεύεται ανά ημερομηνία και συγχρονίζεται με
  MCP. Χωρίς επιλογή χρησιμοποιείται ανάπαυση. Δεν αλλάζει αυτόματα από προπόνηση
  ούτε επηρεάζει τη συντήρηση/τις καταγεγραμμένες καύσεις.
- Εβδομαδιαίο γράφημα ισοζυγίου με θετικό/αρνητικό πρόσημο, ημέρες χωρίς δεδομένα,
  προαιρετική ημερήσια ανάλυση και μέσους όρους ανά ημέρα με γεύματα.
  Το παλιό API `daily_average` παραμένει συμβατό (διαίρεση με 7). Το UI χρησιμοποιεί
  `recorded_day_average`, με `recorded_days` ως παρονομαστή· δεν αποδεικνύει πλήρη ημέρα.
- Οι στόχοι ανάπαυσης/προπόνησης συγκρίνονται μαζί, διατηρώντας μη αποθηκευμένες αλλαγές.
- Κάτω πλοήγηση σε κινητά, ακόμη όταν αυξάνεται το διαθέσιμο πλάτος σε συσκευή αφής.
  Responsive στήλες, safe-area padding, κανονικό pinch zoom χωρίς περιορισμούς
  `user-scalable`/`maximum-scale`. Η ώρα δεν επινοείται για παλιές καταγραφές.

## Νέα εργαλεία MCP

| Εργαλείο | Είσοδος / αποτέλεσμα |
| --- | --- |
| getMealTemplates | `{}` → ιδιωτικά αγαπημένα με id, όνομα, κατηγορία, macros |
| saveMealTemplate | request_id, name, category, calories, protein, carbs, fat· προαιρετικό template_id για αντικατάσταση |
| deleteMealTemplate | request_id, template_id· δεν διαγράφει παλιά γεύματα |
| getDayTypes | date ή start_date + end_date → αποθηκευμένες επιλογές |
| setDayType | request_id, date, day_type: rest ή training |

Τα addMeal/updateMeal δέχονται προαιρετικό `meal_time` (`HH:MM`, Europe/Athens).
`null` καθαρίζει την ώρα· παράλειψη στο update διατηρεί την υπάρχουσα.
Όλα τα writes παραμένουν authenticated, owner-scoped, με idempotent request_id.
Αλλαγή payload με ίδιο request_id απορρίπτεται. Οι ίδιες safeguards ισχύουν για
αγαπημένα και τύπους ημέρας. Τα ακριβή schemas βρίσκονται στο [mcp-tools.json](mcp-tools.json).

Παράδειγμα ChatGPT: «το συνηθισμένο πρωινό μου» → getMealTemplates → παρουσίαση
ποσότητας, ημερομηνίας και macros → ρητό «καταχώρισέ το» → addMeal. Καμία έγκριση
στο dashboard. Μη χρησιμοποιείς saveMealTemplate για να καταγράψεις κατανάλωση.

## Έλεγχοι

`npm test`, `npm run build`, `npm run test:browser`, `npm run mcp:schemas`.
Οι τοπικοί έλεγχοι χρησιμοποιούν PostgreSQL/PGlite, επίσημο MCP HTTP client και
Chromium με προσομοιωμένο Supabase HTTP/OAuth. Περιλαμβάνουν isolation δύο χρηστών,
ανώνυμη απόρριψη, retries, ώρα, διατήρηση παλιών receipts, πρόχειρα χωρίς εγγραφή,
επεξεργασία/διαγραφή/ανάκληση αγαπημένων, επιλογή ημέρας μετά reload, φίλτρα,
πλάτη 320–1280 και zoom/reflow. Δεν αντικαθιστούν έλεγχο πραγματικού Safari/iPhone,
live Supabase OAuth ή την εφαρμογή της migration στο παραγωγικό project.
