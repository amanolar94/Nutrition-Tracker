# Nutrition Tracker

Web εφαρμογή στα ελληνικά για ημερήσια καταγραφή γευμάτων, θερμίδων και πρωτεΐνης.

## Εκτέλεση

Απαιτείται Node.js 22.12+ (ή 24) και npm.

```sh
npm ci --cache /tmp/nutrition-npm-cache
npm run dev
```

## Έλεγχοι

```sh
npm test
npm run build
```

## Λειτουργίες

- Καταγραφή και διαγραφή γευμάτων ανά ημερομηνία.
- Σύνολα θερμίδων και πρωτεΐνης και προσαρμογή στόχων.
- Αποθήκευση στο localStorage του browser, χωρίς λογαριασμό ή server.

Τα δεδομένα δεν συγχρονίζονται μεταξύ συσκευών και χάνονται αν διαγραφεί η αποθήκευση του browser. Οι αριθμοί διατροφής εισάγονται χειροκίνητα. Οι προεπιλεγμένοι στόχοι είναι ενδεικτικοί.
